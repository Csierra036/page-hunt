Cómo se juega y qué modos existen
  • Objetivo: rompe la página a tiros y caza patos. Cada 5 rondas (hasta la 20) aparece un jefe: derriba sus ataques o perderás uno de tus 3 corazones.
  • Armas: los patos sueltan cajas en paracaídas. Dispara al paracaídas y recoge la caja cuando toque el suelo.
  • Doom: el medidor de abajo a la izquierda se llena con el daño que haces. Cuando esté lleno, pulsa Q para desatar un ataque que arrasa toda la pantalla.
  • Recarga perfecta: pulsa la tecla de recarga otra vez cuando la barra esté en la zona verde. Con la rueda o las flechas desplazas la página.
  • DOM real: páginas de este mismo servidor (como la página de prueba). Se rompen sus elementos de verdad.
  • Iframe en vivo: páginas externas que se dejan mostrar dentro de otra web. El daño es una capa encima.
  • Simulación visual: se destruye una captura de la página. La página real nunca se modifica.

Para comprobar una página, el servidor del juego la visita sin cookies ni sesiones. La dirección no se comparte con terceros.
